# Um Dia na Hill Valley Tech 🏢

## Visão Geral

A **Hill Valley Tech** é uma empresa fictícia que serve de palco para este desafio de engenharia. O cenário apresenta cinco sistemas em produção, cada um com seu papel bem definido, operados por um time enxuto mas bem estruturado.

---

## 🏗️ Arquitetura de Sistemas

### **Chronos**
- API Gateway e plataforma core
- Ponto de entrada de todo tráfego da empresa

### **Ledger**
- Data warehouse em PostgreSQL
- Armazena histórico de transações e eventos

### **Reactor**
- Processamento assíncrono via filas de mensagens

### **Beacon**
- Plataforma de observabilidade
- Métricas, logs e alertas
- Interface central para o plantão monitorar o ambiente

### **Lift**
- Produto em beta
- Em amadurecimento pela equipe

## 📋 Formato dos Desafios

### Questões 01-07 e 09-10
Cada questão apresenta:
- Um prompt de IA aplicando o framework indicado no enunciado
- Output executado em um modelo de linguagem
- Justificativa mostrando como os componentes do framework aparecem no prompt

### Questão 08
- Escolha livre: selecione entre os cinco frameworks do capítulo
- Comparação explícita contra duas alternativas
